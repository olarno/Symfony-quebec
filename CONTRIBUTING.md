# Contribuer

Merci de vouloir faire vivre Symfony Québec ! Pour proposer un talk, une salle ou une commandite, [ouvre une issue](../../issues/new/choose) avec le modèle qui correspond. Pour tout le reste (correction, idée pour la carte, nouveau contenu), une issue ou une pull request fait l'affaire.

En contribuant, tu acceptes de respecter le [code de conduite](CODE_OF_CONDUCT.md).

## Conventions de rédaction

### Langues

- Chaque document est d'abord rédigé **en français**.
- Une version **anglaise** suit à la fin du document, dans un bloc repliable :

  ```html
  <details>
  <summary><b>English</b></summary>

  ...

  </details>
  ```

- Les deux versions disent la même chose : quand tu modifies l'une, mets l'autre à jour.
- Les modèles d'issue affichent les libellés dans les deux langues : `Français / English`.

### Écriture inclusive

On suit les recommandations de l'[Office québécois de la langue française](https://vitrinelinguistique.oqlf.gouv.qc.ca/) :

1. **D'abord les formulations neutres** : « les personnes », « la communauté », « l'équipe d'organisation », « tes collègues ».
2. **Sinon, les doublets complets** : « les développeuses et développeurs ».
3. **Pas de formes tronquées** : pas de point médian, de parenthèses ni de barre oblique (`développeur·euses`, `développeur(e)s`).

On tutoie la personne qui lit.

### Dossiers d'événements

Chaque rencontre a son dossier dans [`meetups/`](meetups/), nommé `AAAA-MM-JJ-meetup-NN` (exemple : `2026-10-28-meetup-01`). Il contient un `README.md` avec les informations pratiques, le programme et, après l'événement, le compte rendu et les liens vers les présentations.

# Contributing

Thanks for helping Symfony Québec grow! To offer a talk, a venue or a sponsorship, [open an issue](../../issues/new/choose) with the matching template. For anything else (a fix, an idea for the map, new content), an issue or a pull request works.

By contributing, you agree to follow the [code of conduct](CODE_OF_CONDUCT.md).

## Writing conventions

### Languages

- Every document is written **in French first**.
- An **English** version follows at the end of the document, in a collapsible `<details>` block.
- Both versions say the same thing: when you edit one, update the other.
- Issue templates show labels in both languages: `Français / English`.

### Inclusive writing (French)

We follow the guidance of the Office québécois de la langue française: gender-neutral wording first, full doublets otherwise (« développeuses et développeurs »), and no truncated forms (no middle dot, parentheses or slashes). We address the reader informally (« tu »).

### Event folders

Each meetup has its own folder in [`meetups/`](meetups/), named `YYYY-MM-DD-meetup-NN` (e.g. `2026-10-28-meetup-01`). It holds a `README.md` with practical information, the program and, after the event, the recap and links to the slides.
